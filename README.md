# 6003CEM-Web-API-Development
This is the repo for the introduction to  Web API Development

In this project, I will be developing a backend API Sever about a real estate agency.
Using RestFul API principles I will develop a page that will show properties (homes, flats, etc.)

Node.js with Koa.js

MySQL for database 


Frontend:

ReactJS (For building a responsive SPA)
